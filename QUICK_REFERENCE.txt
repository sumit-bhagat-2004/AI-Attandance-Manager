COLOR CODING REFERENCE
================================================================================

ATTENDANCE STATUS
-----------------
🟢 GREEN    → Present (Good)
🔴 RED      → Absent (Needs Attention)
⚪ GRAY     → Not Marked (Requires Input)
🟡 YELLOW   → Warning (Near Threshold)

SUBJECT TYPES
-------------
📚 Blue     → Theory Classes
🧪 Green    → Laboratory Sessions  
🏋️ Purple   → Training Sessions
🎯 Orange   → Special Events/ECAs

PRIORITY LEVELS
---------------
🔴 RED      → Critical (< 75% attendance)
🟡 YELLOW   → Warning (75-80% attendance)
🟢 GREEN    → Good (> 80% attendance)

ESSENTIAL WORKFLOWS
================================================================================

DAILY ATTENDANCE WORKFLOW
-------------------------
1. Open EduTrack AI dashboard
2. Review today's class schedule
3. Click "Mark All Present" if attending all classes
   OR mark individual classes as Present/Absent
4. Check makeup alerts (right panel)
5. Review daily statistics

WEEKLY REVIEW WORKFLOW  
----------------------
1. Switch to Stats view
2. Review weekly attendance percentages
3. Click "AI-Enhanced Weekly Reports" button
4. Read AI recommendations and insights
5. Plan makeup classes if needed
6. Update ECA activities

MAKEUP CLASS WORKFLOW
--------------------
1. Check Makeup section (right panel) for alerts
2. Click on subject requiring makeup
3. Select from available makeup time slots
4. Confirm makeup class booking
5. Mark attendance when you attend makeup

ECA MANAGEMENT WORKFLOW
----------------------
1. Click "Add ECA" button
2. Fill in activity details:
   - Activity name and description
   - Date and time
   - Category and achievement level
3. Save activity
4. View ECA history in Calendar view

COMMON TASKS & SOLUTIONS
================================================================================

MARKING ATTENDANCE
------------------
Task: Mark today's attendance quickly
Steps:
1. Look at schedule on main dashboard
2. If attending all classes: Click "Mark All Present"
3. If missing some classes: Click individual red X for absent classes
4. Verify all classes are marked (no gray cards)

Task: Correct attendance mistake
Steps:
1. Find the incorrectly marked class
2. Click on the class card
3. Select correct status (Present/Absent)
4. Change is saved automatically

CHECKING PERFORMANCE
--------------------
Task: View attendance statistics
Steps:
1. Stats are always visible in right panel (Schedule view)
2. For detailed stats: Click "Stats" in navigation
3. For trends: Switch to Calendar view
4. For AI analysis: Generate weekly reports

SCHEDULING MAKEUP CLASSES
-------------------------
Task: Schedule required makeup
Steps:
1. Check Makeup section (right panel) for red alerts
2. Click on subject with low attendance
3. Browse available makeup slots
4. Select preferred time
5. Click "Schedule Makeup" to confirm

GENERATING AI REPORTS
--------------------
Task: Get personalized study recommendations
Steps:
1. Click large "AI-Enhanced Weekly Reports" button
2. Wait for AI analysis (may take 1-2 minutes)
3. Review generated report with recommendations
4. Follow suggested study plans and strategies
5. Save report for future reference

================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

COMMON PROBLEMS
---------------
Problem: Page won't load
Quick Fix: Press F5 to refresh, check internet connection

Problem: Attendance not saving  
Quick Fix: Click the class again, wait 2 seconds, refresh page

Problem: Reports not generating
Quick Fix: Check internet, wait 3 minutes, try again

Problem: Mobile menu not opening
Quick Fix: Tap hamburger icon again, refresh page

Problem: Wrong date showing
Quick Fix: Click "Today" in Time Machine controls

Problem: Statistics not updating
Quick Fix: Refresh page (F5), check if attendance is marked

EMERGENCY ACTIONS
-----------------
Attendance Crisis (< 75%):
1. ⚠️ Check Makeup alerts immediately
2. 📅 Schedule all available makeup classes  
3. 🤖 Generate AI report for recovery plan
4. 📞 Contact academic advisor

System Not Working:
1. 🔄 Refresh page (Ctrl+R)
2. 🌐 Check internet connection
3. 🧹 Clear browser cache
4. 📱 Try different browser/device
5. 📧 Contact support if issues persist

PERFORMANCE TIPS
================================================================================

SPEED UP THE APP
----------------
• Use Chrome, Firefox, Safari, or Edge browsers
• Close unnecessary browser tabs
• Clear browser cache weekly
• Ensure stable internet connection
• Keep browser updated

OPTIMIZE DAILY USAGE
--------------------
• Mark attendance immediately after classes
• Use bulk operations when possible
• Check makeup alerts daily
• Generate reports weekly, not daily
• Keep ECA activities updated regularly

MOBILE OPTIMIZATION
-------------------
• Use WiFi when possible for faster loading
• Close other apps when using EduTrack AI
• Enable JavaScript in mobile browser
• Use latest browser version
• Clear mobile browser cache regularly
